## Contributing

Request Timeout is an independent organization, and contributions are welcome.

If you know something we don't, there is a reasonable chance we would like your help.

We are especially interested in people with experience in:

* Python development
* Java development
* Minecraft modding
* Fabric development
* Software testing
* Code review
* Documentation
* Security
* Finding problems before they become much larger problems

You can contribute by reporting bugs, suggesting improvements, opening issues, submitting pull requests, or helping improve existing projects.

## Security
Security is important.

Unfortunately, security is also one of those things where you can spend several hours looking at code and discover that a single line was a terrible idea.

If you have experience with software security, code review, or finding suspicious behavior in programs, your feedback is appreciated.

Please do not publicly post sensitive security issues before giving us an opportunity to investigate them.
